# სანდროს დაბადების დღის მოსაწვევი

ანიმაციური მოსაწვევი ერთ ფაილში: `index.html`. ყველაფერი (სტილი, სკრიპტი, სანდროს ფოტო) ფაილშივეა ჩაშენებული, გარედან მხოლოდ Google Fonts-ის შრიფტი იტვირთება.

## Laravel-ზე დადება

ფაილი Blade-ში არ გადაიტანო: CSS-ის `@media` და `@keyframes` Blade-ის დირექტივებს ეჯახება. დადე როგორც სტატიკური ფაილი:

1. დააკოპირე `index.html` აქ: `public/sandro/index.html`
2. მოსაწვევი გაიხსნება მისამართზე `https://შენი-დომენი/sandro/`

თუ ცალკე route გინდა (`routes/web.php`):

```php
Route::get('/sandro', fn () => response()->file(public_path('sandro/index.html')));
```

## ტექსტის შეცვლა

თარიღი, დრო და მისამართი `index.html`-ში `<div class="details"` ბლოკშია, აღწერა ბმულის გაზიარებისთვის ფაილის თავში `<meta ...>` ტეგებში.
